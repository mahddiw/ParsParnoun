# تاریخ (روز/ماه/سال) نام کارشناس بخش شرکت پروژه دسته‌بندی فنی ساعت (شروع - پایان) مدت (ساعت) شرح خدمات انجام شده وضعیت عملیات

تنظیم و بارگذاری نماد (لوگوی) رسمی مهندسین مشاور پارس پرنون

شما می‌توانید فایل تصویر لوگوی اصلی شرکت (PNG، JPG یا SVG) را از کامپیوتر یا گوشی خود انتخاب کنید تا در صفحه ورود، نوار کناری و سربرگ چاپ رسمی ذخیره و نمایش داده شود.

پشتیبان‌گیری و انتقال اطلاعات (نسخه پشتیبان JSON)

تمامی اطلاعات پرسنل، رمزهای عبور، بخش‌های شرکت، پروژه‌ها و ساعات کارکرد به صورت خودکار ذخیره می‌شوند. همچنین می‌توانید فایل دیتابیس کامل را دانلود یا بازیابی کنید.

راهنمای سرور و هاست رایگان دائمی برای این سامانه

  • ۱. هاست رایگان Netlify Drop (سریع‌ترین روش): وارد سایت app.netlify.com/drop شوید و همین فایل index.html را بکشید و رها کنید تا در ۱۰ ثانیه لینک اینترنتی دائمی و رایگان (https://parsparnoun.netlify.app) دریافت کنید.
  • ۲. سرور رایگان GitHub Pages / Vercel: بدون محدودیت ترافیک و کاملاً رایگان با SSL امن.
  • ۳. دیتابیس ابری رایگان Supabase (اختیاری): برای اشتراک‌گذاری آنلاین لحظه‌ای بین کامپیوترهای مختلف، لینک API رایگان Supabase یا Firebase خود را در کادر زیر وارد کنید.
